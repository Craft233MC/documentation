# 经济系统

服务器经济由 `XConomy` 提供，货币单位为金币。任务奖励、领地创建与箱子商店均使用该货币。

适用子服务器：`Lights`

## 查询余额

- `/balance` 查询自己的余额
- `/bal` 同上
- `/money` 同上
- `/balance <玩家名>` 查询其他玩家余额

新账号初始余额为 0。

## 转账

- `/pay <玩家名> <金额>` 向玩家转账
- `/paytoggle` 开启或关闭接收转账

转账不收取手续费。

## 排行榜

- `/balancetop` 查看余额排行榜
- `/baltop` 同上

## 获取金币

当前金币来源为 [每日任务](/docs/commandAndFunctions/quests) 与 [每日签到](/docs/commandAndFunctions/signIn)。玩家之间的金币也可通过 [箱子商店](/docs/commandAndFunctions/quickShop) 流转。
