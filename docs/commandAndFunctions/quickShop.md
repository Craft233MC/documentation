# QuickShop

适用子服务器: `Terra`, `ABlock`

## 查找商店
列出服务器上所有的箱子商店

用法: `/qs browse`

按物品名称查找商店

用法: `/qs find <物品名称>`

## 创建商店
使用命令在看着的箱子上创建商店，物品为手持物品

用法: `/qs create <价格>`

## 修改数量
使用命令修改看着的箱子上的交易物品数

用法: `/qs amount <数量>`

## 修改价格
使用命令修改看着的商店的交易价格

用法: `/qs price <价格>`

## 切换销售模式
使用命令修改看着的商店的售卖或收购模式

用法: 
- `/qs buy` 切换到收购商店

- `/qs sell` 切换到售卖商店

## 替换物品
替换商店物品至手上的物品

用法: `/qs item`

## 设置商店权限
设置商店的所有权或转让

用法:
- `/qs setowner` 设置商店所有者

- `/qs transferall <玩家名>` 将自己的所有商店转让给某玩家

- `/qs transferall <accept|deny>` 接受或拒绝他人的转让请求

- `qs transerownership <玩家名>` 将正在看着的商店转移给某玩家

- `/qs transferownership <accept|deny>` 接受或拒绝他人的转让请求

## 设置商店
设置商店的其他设置

用法: 
- `/qs sign` 切换商店的告示牌样式

- `/qs toggledisplay` 切换正在看着的商店的物品可见性(掉落物)
