# 语音聊天

Craft233 使用 `Simple Voice Chat` 提供近距离语音。语音在服务器侧处理，无需额外语音平台。

适用子服务器：`Lights`

## 客户端准备

语音功能依赖客户端 mod，仅 Java 版可用。安装与服务器版本兼容的 [Simple Voice Chat](https://modrinth.com/plugin/simple-voice-chat) 客户端 mod 后启动游戏。

未安装 mod 的玩家可以正常游玩，但无法收发语音。

## 使用

进入服务器后 mod 自动连接语音服务，无需填写地址与端口。

- 按 `V` 打开语音设置与群组菜单
- 说话方式（按键说话或语音激活）在菜单内设置
- 48 格范围内的玩家可以听到语音
- 耳语仅 24 格范围内的玩家可以听到

## 群组

语音群组用于跨距离通话。通过 `V` 菜单创建或加入群组，同一群组的成员不受距离限制。

## 排查

- 听不到语音：确认 mod 已加载，并检查系统麦克风权限与输入设备。
- 连接失败：确认客户端 mod 与服务器版本兼容，并检查本地防火墙是否允许 UDP 流量。
