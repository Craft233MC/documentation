# 服务器菜单与切换

Craft233 由代理端与两个子服务器组成。大厅提供菜单入口，生存服通过指令返回。

## 打开服务器菜单

打开子服务器选择菜单，菜单内附带服务器规则入口。

适用子服务器：`Lobby`

用法：`/servers`

## 切换子服务器

在代理端切换子服务器。

适用子服务器：`Lobby`、`Lights`

用法：

- `/server lobby` 切换至大厅
- `/server lights` 切换至休闲生存

## 返回出生点

返回当前子服务器的出生点。

适用子服务器：`Lights`

用法：`/spawn`

## 查看服务器信息

玩家列表页脚显示当前时间、所在子服务器、TPS、MSPT、延迟与在线人数。

按 `Tab` 键打开玩家列表。

## 服务器规则

完整规则见 [Craft233 服务器规则](https://www.craft233.cn/rules)。进入服务器即视为同意该规则。
