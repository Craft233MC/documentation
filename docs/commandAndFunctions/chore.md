# 常用杂项
一些杂项命令或功能的介绍

## 菜单
使用命令打开服务器内菜单，而不是使用物品激活

适用子服务器: `Terra`, `ABlock`

用法: `/menu`, `/cd`
## 切换服务器
使用命令切换服务器或打开服务器切换菜单

适用子服务器: `Lobby`, `Terra`, `ABlock`

用法: 

- `/server <服务器名>` 使用代理端命令切换服务器

- `/servers` 打开服务器切换菜单

## 服务器人数及分布
使用命令查询服务器的总人数及各自分布情况

适用子服务器: `Lobby`, `Terra`, `ABlock`

用法: 

- `/glist all` 全服信息查看

- `/geyser list` 查看在线的基岩版玩家

## 私信玩家
像某玩家发出单独的消息，仅自己和对方可以查看

用法: `/msg <玩家名> <聊天内容>`

## 聊天展示物品
在聊天中展示手持物品，背包，末影箱
::: info
此特性仅Java版支持
:::

用法:
- 在聊天中加入`[i]`展示手持物品

- 在聊天中加入`[inv]`展示背包

- 在聊天中加入`[end]`展示末影箱

## @玩家
用法: 
- `@<玩家名>` @特定玩家

- `@所有人` @所有玩家

## 消息字体颜色
要想在发送的消息使用颜色请使用`&`符号加上颜色字符进行组合

例如`&a我想把这玩意儿染成绿的`

也可以使用`十六进制颜色`,例如`&#FF7F24Doro给你带来了哦润吉`
