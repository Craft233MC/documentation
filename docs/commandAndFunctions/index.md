# 指令及功能🧩

Craft233 由 Velocity 代理与两个子服务器组成：

- `Lobby`：大厅，提供菜单、规则与子服切换。
- `Lights`：休闲生存，主要玩法所在服务器。

大多数指令在所有子服务器通用。标注了适用子服务器的条目，仅在对应服务器生效。
