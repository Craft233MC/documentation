# 聊天与消息

服务器聊天由代理端 `ChatX` 处理，支持频道、私信、提及与聊天记录查询。

## 聊天频道

每次发送消息只进入当前频道。切换频道使用频道指令。

| 频道 | 指令 | 说明 |
| --- | --- | --- |
| 本地 | `/l` | 本子服务器内可见 |
| 跨服 | `/g` | 所有子服务器可见 |
| 管理 | `/staff` | 仅管理组可见，需要对应权限 |

以 `!` 开头的消息自动发送至跨服频道，无需先切换：

```text
!这是一条跨服消息
```

## 房间聊天

房间用于小范围交流，房间号由创建者获得。

- `/room create` 创建房间
- `/room <房间号>` 加入房间
- `/room invite <玩家名>` 邀请玩家加入当前房间

## 私信

- `/msg <玩家名> <消息>` 向玩家发送私信
- `/reply <消息>` 回复最近一条私信
- `/r <消息>` 同上

## 提及玩家

在消息中加入 `@玩家名` 提及玩家。被提及的玩家会收到提示音与界面提示。

## 查询在线状态

- `/online player <玩家名>` 查询玩家所在子服务器
- `/online server <子服务器名>` 查询子服务器在线人数

## 查询聊天记录

- `/chathistory` 列出可查询的频道
- `/chathistory <频道>` 查看该频道最近的消息
- `/chathistory search <频道> <页码> <关键词>` 搜索频道记录

## 管理指令

以下指令需要管理权限。

- `/chatx mute <玩家名> [时间] [原因]` 禁言玩家，时间格式如 `1d5h`
- `/chatx unmute <玩家名>` 解除禁言
- `/chatx reload` 重载配置
