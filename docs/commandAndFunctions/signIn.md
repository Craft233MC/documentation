# 每日签到

`LiteSignIn` 提供每日签到、连续签到奖励与签到排行。

适用子服务器：`Lights`

## 签到

- `/signin` 签到
- `/signin gui` 打开签到日历
- `/signin leaderboard` 查看签到排行

每日只能签到一次。签到顺序计入当日排行，首位签到者获得额外奖励。

## 奖励

| 条件 | 奖励 |
| --- | --- |
| 每日签到 | 面包 ×16、铁锭 ×6 |
| 当日首位签到 | 金锭 ×6、铁锭 ×12 |
| 连续签到 3 天 | 面包 ×32、铁锭 ×12 |
| 连续签到 7 天 | 面包 ×48、铁锭 ×18、金苹果 ×1 |
| 累计签到 100 天 | 金币 ×100、面包 ×48、铁锭 ×18、金苹果 ×1 |

连续签到 3 天的奖励替换当日默认奖励，其他条件在原奖励上追加。

## 时段奖励

- 22:30 至 23:59 签到：牛奶桶 ×1
- 00:00 至 03:00 签到：牛奶桶 ×1
- 12 月 25 日签到：苹果 ×25、金苹果 ×3、金币 ×122.5
