# HuskHomes家插件

适用子服务器: `Terra`, `ABlock`

## 返回
返回到上一次死亡或传送前的位置

用法: `/back`

## 随机传送
随机传送到服务器内的一个位置

用法: `/rtp`

## 玩家间传送
### 申请传送
想一个或所有在线玩家发送传送的申请

用法: 
- `/tpa <玩家名>` 申请传送到一个玩家

- `/tpahere <玩家名>` 向玩家申请传送到自己位置 

- `/tpaall` 向所有在线玩家发送传送到自己位置的申请

### 处理传说申请
接受，拒绝或忽略其他玩家的传送申请

用法: 
- `/tpaccept` 接受传送申请

- `/tpyes` 接受传送申请

- `/tpdeny` 拒绝传送申请

- `/tpno` 拒绝传送申请

- `/tpignore` 忽略传送申请

## 传送到家
传送到一个已设置的家

用法: 
- `/home [家名]`

- `/homes`, `/homelist` 列出所有已设置的家

## 设置家
设置或删除家的位置

用法: 
- `/sethome <家名>` 新设置一个家

- `/delhome <家名>` 删除一个家

- `/phome [家名]` 传送到一个公开的地点

- `/phoms`, `/phomelist`, `/publichomes`, `/publichomelist` 列出所有公开地点`

## 编辑家
编辑家的位置及其他参数，例如公开性，描述等

用法: 

- `/edithome <家名> rename <新家名>` 重命名一个家

- `/edithome <家名> description <描述>` 设置一个家的描述

- `/edithome <家名> relocate` 更新家的位置到当前坐标

- `/edithome <家名> privacy` 切换一个家公开性(默认不公开)

## 传送到地标
传送到一个服务器的地标传送点的地标

用法: 

- `/warp <地标名>` 传送到一个地标

- `/warps`, `/warplist` 列出所有地标
