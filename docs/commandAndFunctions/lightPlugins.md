# Light系小工具插件
Light系列插件是Craft233自主编写的工具类轻量插件，以满足Craft233的需求

同时，Light系插件完全兼容Paper及Folia平台，且保持开源

适用子服务器: `Terra`, `ABlock`

## LightSuicide
用于结束玩家生命，立即回到出生点(不死图腾无效)

用法: `/suicide`

## LightChainBreak
连锁破坏插件。目前Craft233开放了两个连锁组

分别为`矿物与镐`, `原木与斧头`

连锁需要可挖掘(会掉物品)和足够耐久度时才会生效

用法: `/lcb toggle` 切换连锁破坏开关
