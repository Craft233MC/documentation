# 每日任务

`BetterQuests` 为每位玩家提供三个个人任务槽位，并定时发布全服任务。任务奖励以金币结算。

适用子服务器：`Lights`

## 查看任务

`/quests` 列出全部个人任务与当前全服任务，包含描述、进度与奖励。

任务槽位在完成后自动补充新任务。服务器重启后，个人任务与进度会重新抽取。

## 个人任务类型

| 类型 | 目标 |
| --- | --- |
| 垂钓 | 钓取指定数量的鱼、指定鱼类、多个鱼种或分布在多片开放水域的渔获 |
| 探索 | 徒步前进、发现新区域或发现不同生物群系 |
| 地标旅行 | 按路线抵达服务器地标 |
| 物资征集 | 收集并提交指定物品 |
| 生物狩猎 | 击败指定生物、族群或以指定方式击败生物 |
| 多样饮食 | 品尝不同种类的食物 |
| 资源开采 | 开采指定矿物 |
| 自然生物发现 | 寻找并对自然生成的生物右键 |

## 提交与出发

部分任务需要在聊天中点击操作，也可使用指令：

- `/quests submit <槽位|GLOBAL>` 提交物资征集任务所需物品
- `/quests start <槽位|GLOBAL>` 开始地标旅行任务

地标旅行任务点击后需等待 5 秒传送至起点，期间移动或受伤会取消传送。行程中禁止长距离传送、使用鞘翅与跨世界移动，违反后行程重置。

## 全服任务

全服任务每 40 至 120 分钟发布一次，所有玩家共享同一目标并独立累计进度。第一名完成者获得奖励，任务随即结束。

全服任务的奖励为普通同类任务的 3 至 6.5 倍。
