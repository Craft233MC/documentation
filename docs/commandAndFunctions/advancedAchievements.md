# 高级成就
额外的成就体验！

适用子服务器: `Terra`, `ABlock`

## 成就进度
显示当前advancedachievements插件的成就完成进度(箱子GUI)

用法: `/aa list`

## 成就排行榜
插件服务器玩家间advancedachievements插件的总排行榜

用法: `/aa top`

## 获取成就书
获取一本带有AdvancedAchievements成就记录的书

上面记录了目前拥有的成就及成就达成的时间

用法: `/aa book`

## 排行
显示一定期限内达成成就的玩家排行榜

用法: 
- `/aa week` 周排行榜

- `/aa month` 月排行榜

## 玩家成就可见性
切换是否可以查看其他玩家获得成就的通知，设置只保留到下次重启服务器前

用法: `/aa toggle`

## 查看特定成就的获得者
查看某项成就拥有的玩家以及拥有的时间

用法: `/aa inspect <成就名>`
