# 正式进入🧭
从此刻正式添加Craft233服务器并加入

## 服务器地址说明
目前Craft233有几个连接地址，默认连接地址为`mc.craft233.top`，端口默认

默认连接地址对联通用户的解析为直连，其他网络为阿里云中转

如果有连接延迟过高或其他需求，可以尝试使用下面的这些地址

- `aliyun.mc.craft233.top`  阿里云中转地址

- `mix.mc.craft233.top`  联通直连地址(支持v4和v6)

- `v4.mc.craft233.top`  联通直连(仅ipv4)

- `v6.mc.craft233.top`  联通直连(仅ipv6)
